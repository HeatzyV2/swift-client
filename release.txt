## Changes (v1.1.3)

### 🧩 Swift Client mod 1.2.0
- Ships the new mod: 40 new modules (Minimap, Waypoints, PvP Info, Motion Blur, Item Physics, Friends...), a reorganised mods menu and Bloomy as the one theme.
- The launcher now downloads the latest Swift Client mod from GitHub before each launch: new mod versions reach players without waiting for a launcher update.

### 🌍 Host World
- Hosted worlds get an address that works while 25565 is used by another server (`pseudo.swiftclient.fr:<port>`).

## Changes (v1.1.2)

### 🔄 Automatic updates actually work now
- The updater was pointed at a domain that was never set up, so "Check for updates" always failed. It now reads the update file GitHub publishes on every signed release.
- The launcher checks once on start-up and offers the update as a toast — install is blocked while a game is running or a download is in progress.

### 🌐 New Servers tab
- Lists partner servers with live status, player count and MOTD.

### 🏠 Home
- Live news and changelog can now be updated from the Swift Client backend without a launcher release.
- Quick Start creates and launches the recommended instance in one click.

### 🔒 Backend
- `api.swiftclient.fr` is enforced over HTTPS (except localhost, for development); the backend can now terminate TLS itself when no reverse proxy is available.

## Changes (v0.1.0)

### ✨ First Swift Client release
- New identity, interface and navigation: Home, Instances, Worlds, Screenshots, Skins, Settings.
- Home is built around launching: the selected instance, its version and loader, and one Play button.
- No telemetry, no analytics, no crash data sent anywhere.
- CurseForge, instance sharing by code and automatic updates are switched off until the Swift Client online service exists. Modrinth works as before.
- Backups and share packs made with Spectra Launcher can still be imported.
